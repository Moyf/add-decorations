# Task Decorator

A focused task management plugin for Obsidian that adds visual decorations to help you concentrate on what matters.

## Features

- **Task Highlighting**: Highlights a configurable number of tasks to help you focus
- **Completed Task Styling**: Automatically styles child items under completed tasks
- **Smart Level Detection**: Correctly handles nested task hierarchies
- **Real-time Updates**: Settings changes apply instantly without restart
- **Lightweight**: Minimal performance impact with efficient decorations

## How it works

- Configure how many tasks should be highlighted in settings
- Tasks beyond the limit get a subtle fade effect
- When you complete a parent task, all its child items get special styling
- Only child items (deeper indentation) are affected by parent completion status
